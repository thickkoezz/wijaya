Wijaya — NTFS baca-tulis untuk macOS

Installer ini memasang:

  • Wijaya.app  →  /Applications/Wijaya.app
  • ntfs-3g (build FUSE-T)  →  /usr/local/bin/ntfs-3g
  • libfuse-t runtime  →  /usr/local/lib

Prasyarat: FUSE-T harus sudah terpasang lebih dulu:

brew install --cask macos-fuse-t/homebrew-cask/fuse-t

Setelah instalasi kamu perlu memberi Full Disk Access — langkahnya ada di akhir dialog ini.
